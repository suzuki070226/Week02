# Week02 POSSE課題

## 制作内容

Tailwind CSSを使って、POSSE CAFEのメニューページを制作しました。コーヒー・ティー・フードの3種類のメニューを掲載しています。

## 工夫したところ

* `max-w-2xl`：画面が横に広がりすぎないように、ページの最大幅を設定しました。
* `mx-auto`：ページ全体を中央に配置しました。
* `shadow-md`：メニューに影をつけ、カードのように見せました。
* `rounded-lg`：カードの角を丸くして、柔らかい印象にしました。
* `p-2`：カードの内側に余白を設け、文字を読みやすくしました。
* `hover:bg-blue-700`：注文ボタンにマウスを乗せると色が変わるようにしました。

## 苦労したところ

最初はメニューが画面いっぱいに広がってしまい、見た目が整いませんでした。そこで、`max-w-2xl` と `mx-auto` を使って横幅を調整し、中央に配置することで解決しました。

また、HTMLの閉じタグの抜けや不要な記号があったため、コードを確認して修正しました。

## デザインの工夫

メニューが見えやすいように配色を心がけました。また、注文ボタンには青色を使用し、目立つようにしました。
